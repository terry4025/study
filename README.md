# 결 스터디 — 여러 책을 위한 학습 플랫폼

원격 기준: `cc09c8aff9847120c6c3fc3140fbae5579060d1c`에 이미 적용된 새 리더를 확장한 변경입니다.

## 제공 범위

여섯 권의 서재와 별도의 공통 기초 코스를 지원합니다. PBRT가 현재 학습 자료이며 OSTEP·CS:APP·DDIA는 기존 메타데이터를 유지한 준비 상태, 나머지 두 권은 선정 전 슬롯입니다. 준비 중인 책에 가짜 본문이나 학습 진도를 넣지 않습니다.

PBRT는 **학습 동반자이며 완역본이 아닙니다.** 공식 번호 절 105개를 안내하고, 9~16장 및 부록 A~C의 55개 독자 길잡이를 추가했습니다. 기존 1~8장 50개 노트와 후반 주제 입문 24개는 보존합니다. 공통 기초 8개는 별도로 관리합니다. 실제 저장소 연결 시 PBRT 129개 + 기초 8개, 총 137개 수업입니다. 이 개수를 원문 번역 완성률로 사용하지 않습니다.

## 기능

- 책별 목차/콘텐츠/출처/용어 제공자, 공통 기초 참조, 전체/현재 책 검색.
- 책별 읽음·북마크·문단 메모·위치·답안·퀴즈 시도·원문 읽기 기록.
- 이전 v2 기록 자동 이관 및 원본 보존. v3 JSON 내보내기/검증 후 백업·복원.
- 미검수 원문/그림 표시. 원문 대조 검수 상태와 사용자 진도를 분리.
- 밝게/종이/어둡게, 본문 크기/너비/줄간격, 반응형 목차.

```
npm install
npm run build
node scripts/check-platform.mjs
npm run dev
```

기존 `node scripts/check-reader.mjs` 명령도 새 검사로 연결됩니다. 다음 책의 추가는 `src/reader/books/additions.ts`에서 처리합니다. 메타데이터/수업 제공자를 바꾸면 화면 구현을 다시 만들 필요가 없습니다.
