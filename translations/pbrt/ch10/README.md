# PBRT 4판 10장 — 첨부 원문 기반 한국어 본문

## 실제 범위

10장 도입부, 10.1~10.5 전체 절, 추가 읽기 설명, 원서 연습문제의 한국어 번역 초안입니다. 요약·길잡이로 대신하지 않습니다. 원문 대응 텍스트 단위 476개 중 373개를 번역했고, 참고문헌 103개 항목은 검색 가능한 저자·논문명·출판 정보를 보존했습니다. 원문 주석 5개도 번역했으며, 초보자 학습 도움·정정 역주 28개는 본문과 별도 데이터입니다.

모든 문장에 대한 독립 전문 감수 완료나 첫 번째 책 전체 완료를 뜻하지 않습니다. 기존 1~8장 전수 검수 및 11~16장·부록 본문 번역은 남아 있습니다.

## 데이터와 읽기 페이지의 차이

`*.ko.json`의 `{{0}}` 같은 기호는 원문 안의 수식 SVG, 코드 식별자 또는 참조 링크에 대응하는 토큰입니다. 이를 임의로 문장이나 숫자로 바꾸지 마세요. 빌더가 **사용자가 첨부했던 동일 원문 ZIP**에서 토큰을 복원합니다. JSON만 직접 웹페이지에 출력하면 완성된 본문이 되지 않습니다.

현재 저장소에는 10장 번역 데이터, 체크섬, 그림 추출 위치, 리더 재생성 도구가 있습니다. 9·10장 통합 완성 HTML과 이미지 파일은 대화에서 별도 ZIP으로 전달합니다. 이 커밋은 해당 정적 파일들을 기존 앱에 설치하거나 호스팅 배포한 것이 아닙니다. 따라서 기존 앱에 존재하지 않는 파일을 가리키는 링크를 추가하지 않습니다.

## 검사

프로젝트 루트에서 다음을 실행합니다. 첫 명령에는 외부 패키지가 필요 없습니다.

```powershell
py tools/pbrt/check_ch10.py
py -m compileall -q tools/pbrt
```

단위 ID 누락·중복·상태 겹침, 한국어 데이터의 정규화 JSON SHA-256, 역주 대상 ID를 확인합니다. 언어의 의미를 자동으로 감수하는 검사가 아닙니다.

## 첨부 원문 ZIP으로 10장 리더 만들기

Python 3.10 이상에서 실행합니다. 의존성 설치는 인터넷이 필요할 수 있지만, 본문 생성기는 인터넷을 사용하지 않습니다.

```powershell
py -m pip install -r tools/pbrt/requirements.txt
py tools/pbrt/build_ch10.py "C:\원문\pbrt-source.zip" --out "build\pbrt-ch10"
```

생성된 `build/pbrt-ch10/index.html`을 엽니다. 한국어·영문·대조 모드, 본문 검색, 글자 크기, 다크 모드, 참조 코드 펼치기를 지원합니다.

이미 존재하는 출력 폴더는 덮어쓰지 않습니다. 원문 HTML/PDF의 체크섬이 첨부 스냅샷과 다르면 중지합니다. 원문 텍스트 단위와 번역 토큰을 비교한 뒤, 첨부 PDF의 24개 그림을 `figure-provenance.json`의 페이지·좌표로 재생성합니다. 그림은 정적 화면이며 원문의 대화형 보기 전체가 아닙니다. 이 빌더만으로 9장이나 다른 장을 새로 생성하지는 않습니다.

## 수행한 로컬 검증

- 원문 단위와 번역 토큰 대응, 298개 코드 조각 DOM 블록 보존, 중복 DOM ID 및 로컬 참조 검사. 298은 중첩/반복을 포함한 블록 수이며 서로 다른 프로그램 수가 아닙니다.
- 8개 본문 페이지를 320/390/768/1440px와 본문 24px로 격리 렌더링한 32개 레이아웃 확인.
- 해당 환경에서 전체 가로 넘침, 로딩한 그림의 실패 및 JavaScript 오류가 없음을 확인.
- 원문 ZIP으로 재생성 도구 실행 성공.

브라우저의 실제 localhost/file 이동이 실행 환경에서 차단되어 `set_content`와 테스트용 저장 객체를 사용했습니다. 실제 사이트의 History·LocalStorage 통합, 사용자 PC 실기기, 전체 프로젝트 `npm run build`를 통과했다는 의미가 아닙니다.

## 배포 상태

GitHub 커밋/PR과 웹 호스팅 배포를 구분합니다. 연결된 Vercel 팀의 프로젝트 목록에서는 study 프로젝트를 찾지 못했고, 배포 액션은 `Tool deploy_to_vercel not found` 오류를 반환했습니다. GitHub Pages도 확인 당시 활성화되어 있지 않았습니다. 다른 사용자의 프로젝트를 덮어쓰거나 임의의 호스팅을 완료 처리하지 않았습니다.

9·10장 통합 ZIP의 `apply.py`는 기존 앱 소스의 체크섬을 확인하고 백업 후 정적 파일과 링크를 설치합니다. 설치와 클라우드 배포는 별도입니다.
