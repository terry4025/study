# 책상 리더 설계

기존 UI 컴포넌트와 스타일은 재사용하지 않는다. React·TypeScript, 콘텐츠 데이터와 그림 자산은 보존하고 화면을 새로 구현한다.

종이 배경, 짙은 본문, 차분한 녹색 강조, 얇은 선과 여백으로 구성한다. 영어 제목·장 번호는 세리프, 한국어 본문은 시스템 글꼴을 사용한다. 외부 폰트가 로딩되지 않아도 읽을 수 있다. 모든 문단을 배경 카드에 넣지 않는다.

서재는 책과 이어 읽기, 수학 준비실을 우선한다. 목차는 제공 범위와 개인 진도를 분리한다. 리더는 왼쪽 목차와 중앙 본문을 기본으로 하고 용어·메모·절 내부 목차를 필요할 때 보조 패널에서 연다. 작은 화면에서는 목차와 도구가 별도 뷰로 열린다.

검색은 본문·코드·수식 설명까지 포함한다. 절과 블록을 함께 지정해 결과 위치로 이동한다. 일반 절 이동은 pushState를 사용하고 popstate를 처리한다. 목차의 현재 절은 본문 스크롤과 독립적으로 보이도록 유지한다.

문단 위치는 절 ID와 블록 인덱스, 콘텐츠 개정 버전으로 저장한다. 개정이 다르면 같은 블록이라고 가정하지 않고 비율로 복원한다. 편집기를 도입할 때는 영구 문단 UUID를 별도로 두는 것이 적절하다.

기록 가져오기는 검증된 2MB 이하 v2 JSON을 병합한다. 중복된 기존 메모·풀이·위치는 유지한다. 저장소 차단·용량 초과 오류를 숨기지 않는다. 클라우드 동기화는 없다.

자료 상태는 legacy/original/correction으로 분리한다. 영어 참고를 검증된 원문으로 표시하지 않는다. 그림 확대와 파일 존재 확인은 캡션 매핑 검수와 다른 기능이다.

button/label/input/heading/nav와 이름 있는 아이콘 버튼, 키보드 초점, native dialog, Escape, 본문 건너뛰기, reduced motion을 제공한다. 코드·수식 자체의 가로 스크롤은 허용하되 페이지 전체 넘침은 검사한다. WCAG 인증이나 모든 보조기기의 사용 검증을 주장하지 않는다.
