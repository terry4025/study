## 이 변경이 완료한 것과 완료하지 않은 것

최초 기준: `cc09c8aff9847120c6c3fc3140fbae5579060d1c`.

작업 중 추가된 다중 도서 업그레이드 `d5898e2ee657d2b47804966873b249e129ddd50e`를 통합 기준으로 갱신했다. 책별 수업 제공자·사용자 지정 어댑터·검색 실패 처리·부록 정렬을 보존한다. `main`은 직접 수정하거나 배포하지 않는다.

이 변경은 기존 한국어 노트에서 확인한 오류에 대한 **25개 교정 규칙**과 표시 오류 수정이다. 1~8장 전체의 문장별 원문 대조를 완료한 것이 아니며, 9~16장·부록의 새 완역을 포함하지 않는다. 입문 강의나 길잡이를 번역 완료로 간주하지 않는다. 다른 5권의 제목이나 링크는 확정하지 않는다.

## 자료 보존 원칙

- `src/data/books/pbrt-4ed/content/`의 원본은 덮어쓰지 않는다. 리더가 읽을 때 정확한 절·필드·문구에만 교정한 한국어 설명을 적용한다.
- 일치하지 않는 문구를 유사도나 임의 추측으로 바꾸지 않는다. 검사 명령은 찾지 못했거나 여러 번 발견된 규칙을 보고한다.
- 한국어 문단이 바뀌면, 대응이 깨진 영어 노트를 원문처럼 보여 주지 않는다. 실제 영어 원문은 출처 링크에서 확인하도록 표기한다.
- 원본 코드와 식은 임의로 축약하거나 재생성하지 않는다. 새 설명도 전수 검수·완역 인증으로 표시하지 않는다.
- 6.5의 이미 사용 중인 정정 해설 문단 ID는 유지한다. 복원하는 관련 노트에는 별도 접두사를 붙여 메모의 연결 충돌을 피한다.
- 6.5의 잘못 대응된 기존 도판은 경고 블록으로 격리하여 그대로 다시 노출하지 않는다. 도판 원본은 삭제하지 않는다.
- 그림 파일의 존재 검사와 그림 내용·캡션의 의미 대조는 별개이다. 이번 변경은 그림 의미 대조를 완료하지 않았다.

## 실행한 검사

작성 환경에서 TypeScript 5.8.3으로 변경된 모듈의 strict 컴파일을 수행하고, 단위·발췌문 기반 fixture 검사 20개를 통과했다. 검사에는 LaTeX 명령 보존, 입력 불변성, 규칙의 반복 적용 안전성, 책별 범위 제한, 기존 6.5 블록 보존, ID 충돌 방지와 최신 다중 도서 제공자·어댑터·부분 검색 결과 보존이 포함된다.

**제한:** 원격 저장소 전체를 작업 환경으로 내려받지 못해 50개 실데이터에 대한 전체 audit와 production build는 여기서 실행하지 않았다. 최종 컴파일은 실제 `src/types/book.ts`를 가져와 Git blob SHA를 확인하고, 최신 업그레이드의 reader 타입을 사용했다. 실행 검사는 작은 fixture 데이터를 사용했다. 20개 검사의 통과가 실제 25개 원문 매칭 또는 전체 번역 정확성의 인증은 아니다.

실제 저장소에서 의존성 설치 후 다음을 실행한다.

```sh
npm run build
node scripts/check-pbrt-content.mjs --unit
node scripts/check-pbrt-content.mjs --audit
```

`--audit`는 실제 `SECTIONS_MAP`을 읽어 규칙 적용 위치, 수식 파싱 오류, 누락 이미지 경로, 중복 블록 ID를 보고한다. 문제가 남으면 종료 코드 1을 반환한다. 내용의 의미 정확성을 자동으로 인증하지 않는다.
