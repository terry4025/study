## 결과와 범위

1~8장은 **기존에 존재하던 50개 노트 전체를 대조한 1차 편집 검수**입니다. 원문의 목차·개념·수식·코드·그림과 기존 설명을 비교해 발견한 오류를 직접 고쳤습니다. 이 작업을 원문 전체 완역으로 간주하지 않습니다. 각 절의 원문 소제목 목록과 검수 범위는 `pbrt-audit/sections.json`에 있습니다. 추가적인 세부 구현 설명이 원문에만 남아 있는 절이 존재합니다.

## 화면·동작 검사와 한계

현재 환경의 브라우저는 localhost 직접 탐색을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단했습니다. 이 정책을 우회하거나 실제 사용자 PC를 제어하지 않았습니다. 대신 동일한 앱 모듈에 테스트용 URL/History/Storage와 로컬 이미지 응답을 주입해 메모리 내에서 실제 콘텐츠를 렌더링했습니다.

- **기존 50개 절 + 9~16장 62개 수업 = 실제 콘텐츠 112개**를 320px, 1440px에서 본문 24px로 렌더링한 **224개 조건 통과**. 최종 결과에서 전체 페이지 가로 넘침·이미지 실패·수식 표시 오류·JavaScript 예외 없음.
- 발견한 오류를 실제로 수정했습니다: 번역 본문이 글자 크기 설정을 따르지 않던 CSS, 기존 네 절의 긴 인라인 수식 때문에 생긴 모바일 가로 넘침, 이중언어 표의 표시 선택자.
- 저장·북마크·메모·읽음·재초기화 복원·어두운 테마·영문 대조·검색·불허 HTML 제거·영문 표·390/768px 표 레이아웃 **12개 동작 검사 통과**. 저장·탐색은 주입한 메모리 객체이며 실제 브라우저 LocalStorage/History 통합 검사와 구분합니다.
- Node 서버는 실제 127.0.0.1 HTTP 요청으로 HTML/JS/CSS/본문 응답을 확인했습니다. 소스 루트·경로 이탈·없는 파일 노출을 거부하고 POST를 405로 거부하는 11개 요청 결과를 기록했습니다. HTTP 검사는 브라우저 실기기 테스트를 대신하지 않습니다.
- PDF에서 복원한 도판 연락표를 시각 확인했습니다. 자동 그림 경로 검사만으로 캡션 의미 일치가 보장된다고 보지 않았습니다.

Windows 사용자 실기기, 실제 브라우저 origin별 기록 이전, 독립 전문가의 수학·번역 감수는 완료하지 않았습니다. 기록은 내보내기/불러오기로 보존할 수 있고, 서버는 외부 네트워크에 바인딩하지 않습니다.

## 완료와 미완료를 구분

이번 요청의 **13~16장 실제 본문 번역 초안 작성**과 **기존 1~8장 50개 절 전수 1차 검수·직접 교정**을 수행했습니다. 9~12장 자료까지 포함하여 로컬에서 한 앱으로 읽는 실행본을 제공합니다.
