## 실제 테스트 환경과 한계

- Node.js 22.16.0, 로컬 TypeScript 5.8.3으로 새 pure TypeScript 모듈을 검사했습니다. 저장소에서 지정한 TypeScript 6.0.2와 동일한 컴파일러 검사가 아닙니다.
- 기존 타입 계약을 반영한 별도 테스트 파일을 사용했습니다. React 호스트와 기존 책 전체를 포함하는 실제 저장소의 `npm run build`는 실행하지 못했습니다.
- 독립 HTML 미리보기는 KaTeX 0.16.27의 MIT JavaScript를 포함합니다. 적용 후 앱에서는 기존 package.json에 지정된 KaTeX 의존성을 사용합니다. 두 버전의 전체 기존 수식 호환성까지 확인한 것은 아닙니다.
- 이 환경의 Chromium은 `file://`와 localhost URL 탐색을 정책상 차단했습니다. 따라서 Playwright `set_content`로 로컬 HTML 바이트를 렌더링하고, URL·저장소는 메모리 테스트 드라이버로 대체했습니다. 실제 Chromium의 DOM·CSS·MathML·SVG·폼·native dialog를 사용했지만, 네이티브 History/LocalStorage·파일 더블클릭 실행·실제 HTTP 서버 통합 테스트는 아닙니다.
- 드라이버는 배포하는 미리보기 HTML과 앱 코드에는 들어 있지 않습니다. 배포본은 실제 History API와 localStorage를 사용합니다.
- Linux Chromium의 데스크톱·모바일 크기 화면을 확인했습니다. 실제 Windows Chrome/Edge, Android, iOS/Safari 기기 검증은 남아 있습니다.
- 기존 자료의 미검수 캡션과 영어는 자동으로 원문 일치 판정을 하지 않습니다. 전체 문장·그림·코드 정확성 검수와 공개 이용 권리 확인은 남아 있습니다.
