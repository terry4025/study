# 콘텐츠 검수 원칙과 현재 범위

## 완료와 읽음은 다릅니다

1. 자료가 존재함: 실제 열 수 있는 본문·노트·안내가 있음.
2. 원문 범위 검수: 해당 절이 다루는 정의·조건·공식·알고리즘·예외를 대조하고 누락을 기록함.
3. 학습자의 읽음: 개인이 직접 남기는 기록.

현재 원문 지도 105개 절의 `review`는 모두 `pending`입니다. 새 55개 읽기 안내는 각 절에 들어가기 전의 짧은 준비 자료이며, 상세 강의·완역이 아닙니다. 번호 있는 절 연결 105/105를 책 완성률 100%로 표현하지 않습니다.

## 초보자용 설명의 기준

먼저 어떤 문제를 풀려는지 설명하고, 작은 숫자로 계산한 다음 기호의 의미와 단위를 소개합니다. 비유의 적용 범위도 명시합니다. 미분은 입력 변화에 대한 출력 변화, 적분은 작은 기여를 모으는 관점으로 시작하되 수학적 정의·성립 조건을 없애지 않습니다. 새 예제는 독립 학습 예제라고 표시하며 원서의 측정값이나 실험 결과로 오인시키지 않습니다.

‘언제나’, ‘100%’, ‘오차 없음’은 증명된 조건 없이 사용하지 않습니다. 물리 모델의 가정을 자연법칙으로 바꾸지 않습니다. 반사율·BRDF·확률밀도, 방사휘도·휘도, 소멸·흡수·산란은 서로 구분합니다.

## 원문 대조 체크

- 정의·성립 조건·예외를 유지했는지 확인합니다.
- 수식의 분모·부호·적분 영역·변수·단위를 확인합니다.
- 코드가 원문인지 독자 축약 예제인지 구분합니다.
- 그림의 파일·그림 번호·의미·삽입 위치·캡션을 함께 대조합니다.
- 영어 노트가 실제 원문과 같다는 확인 없이는 Original English로 표시하지 않습니다.
- 출처는 실제 사용한 공식 절로 연결합니다.
- 중요한 누락을 보충하거나, 범위를 줄인 자료임을 눈에 띄게 명시합니다.

## 기존 노트

원본 50개 노트는 `src/data/books/pbrt-4ed/content`에 보존됩니다. 기존 리더 어댑터의 일부 교정과 6.5 독자 정정 해설은 유지했습니다. 원본 전체가 교정 완료된 것은 아닙니다. 기존 그림 캡션은 미검수로 표시하고 기본적으로 접습니다. 공식 번호와 파일 의미의 모든 조합을 검증한 상태가 아닙니다.

## 현재 추가 작업에서 하지 않은 것

PBRT 전권·부록 전체 번역, 원문 모든 코드 조각과 도식의 한글화, 기존 노트 전 문장·캡션의 전수 편집 검수, 원서 연습문제 전체 풀이, 계정 기반 기기간 진도 동기화, 기존 자료의 공개 배포 권리 인증은 완료하지 않았습니다.

자동 테스트는 누락된 파일·ID·수식 구문·저장 형식·UI 회귀를 검사합니다. 자연스러운 문장이 사실과 맞는지, 모든 개념이 들어 있는지는 별도의 내용 검수입니다.
