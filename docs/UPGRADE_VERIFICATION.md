## 브라우저 환경 제한

시스템 Chromium이 HTTP/HTTPS/file URL 이동을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단했습니다. 브라우저 정책을 변경하거나 우회하지 않았습니다. `about:blank`에 콘텐츠를 주입하고 `ReaderEnvironment` 테스트 경계에서 메모리 URL/History/Storage를 제공했습니다. DOM, 클릭, 키보드, dialog, MathML, CSS, 레이아웃은 Chromium에서 실제 실행했습니다.

따라서 이 결과를 **실제 웹 서버 접근, 실제 History 뒤로 가기, 네이티브 LocalStorage 영속성, 다운로드 권한, 모바일 실기기 검사 통과**로 표현하면 안 됩니다. `scripts/browser-smoke.mjs`는 이 남은 통합 검사를 실제 로컬 서버에서 수행하기 위해 제공한 코드이며, 이 컨테이너에서는 실행 완료하지 못했습니다.

## 기준 소스 확인 방식

GitHub 연결로 현재 main과 reader 파일들의 blob SHA를 조회했습니다. 이전 패키지에 포함된 로컬 reader 파일이 현재 원격과 동일한지 Git blob SHA로 확인한 뒤 그 바탕으로 확장했습니다. App과 README도 현재 SHA와 일치했습니다. 원격 저장소 전체를 내려받아 npm install/build한 것과는 다릅니다.

원격 기존 50개 본문, 이미지 파일 전체, 실제 프로젝트 의존성을 컨테이너에 모두 가져오지 못했습니다. 기존 adapter는 명시적인 합성 자료로 equation/그림 경고를 확인했습니다. 패키지 적용 테스트도 기준 overlay에 합성 package/data 보호 파일을 둔 별도 복사본에서 진행했습니다.

## 제공한 검사 코드

`tests/platform-invariants.cjs`에는 실행한 29개 모듈 검사와 합성 테스트 자료가 있습니다. `scripts/check-platform.mjs`가 프로젝트에서 실제 데이터/타입/이미지 경로/설치된 KaTeX와 함께 이를 실행합니다. 테스트 데이터는 실제 책에 등록되지 않습니다.
