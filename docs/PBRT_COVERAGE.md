# PBRT 제공 범위 — 완역 완료 표시 금지

## 이번 추가

- 번호가 붙은 공식 절 105개를 탐색 manifest로 연결: 본문 1~8장 50개 / 9~16장 39개 / 부록 A5+B7+C4 =16개.
- 9~16장 및 부록의 55개 절에 **독자 읽기 길잡이**를 1개씩 연결. 원문 문장을 재번역하거나 원서의 전체 유도/코드/그림을 복제한 것이 아님.
- 길잡이 구조: 개념 질문 → 작은 수치 예제 → 적용 조건 → 실제 원문 링크 → 독립 확인 문제.
- 공식 장 도입부·Further Reading·Exercises 링크도 제공. 원서 연습문제의 번역/해답을 제공한 것은 아님. 서문/References/Indices는 공식 전체 목차 링크에서 접근.
- 기존 24개 후반 주제 입문 강의는 ID를 유지하여 보존.
- 공통 기초 8개는 별도 자료 제공자로 분리.

## 실제 저장소 연결 시 수업 수

PBRT: 기존 50개 + 보존한 입문 24개 + 신규 길잡이 55개 = 129개 수업.
공통 기초: 8개. 전체 연결 시 137개.

129개 수업과 105개 원문 절은 같은 단위가 아님. 독립 실행 미리보기에는 기존 50개 데이터와 원서 이미지가 없으므로 PBRT 79개 + 기초 8개, 총 87개만 실행됨. 미리보기의 원문 목차는 기존 50개 절을 원문 링크로 표시함. 실제 저장소를 적용하면 기존 provider가 연결함.

## 검수 상태

- 기존 1~8장: 전체 문장/수식/코드/그림 캡션 원문 대조가 완료되지 않음. 이전 리더의 일부 정정/6.5 독자 정정 해설은 유지. 이번 업데이트가 기존 번역을 전부 고쳤다는 의미가 아님.
- 기존 그림: 번호/캡션 매핑을 신뢰하지 않도록 **그림 자체도 기본 접힘**. 사용자가 열면 보존 자료를 확인할 수 있음. 이것은 오류 정정이 아니라 미검수 표시 강화임.
- 신규 55개: 형식/계산 예제/수식 표시/참조 연결 기본 점검. 독립 그래픽스 전문가의 전체 원문 대조 검수를 받은 것이 아님.
- 원문 대조 검수 완료 섹션: 0. 완역: 제공하지 않음.

## 권리

PBRT 저작권 링크는 CC BY-NC-ND 4.0: https://creativecommons.org/licenses/by-nc-nd/4.0/
원문이 인터넷에 공개되어 있거나 비상업적 학습 목적이라는 이유만으로 전체 번역의 공개 배포 허락이 생기지 않음. 별도 허락/적용 가능한 예외 여부는 따로 확인해야 함. 이 패키지는 PBRT 번역권을 획득했다는 뜻이 아님. 기존 저장소의 번역과 이미지 권리도 이번 코드 변경으로 해결되지 않음.

## 누락 없이 끝내기 위한 남은 기준

1. 기존 50개 절의 주장/성립 조건/구현 판본/그림 의미를 원문과 대조하여 구체적 검수 기록을 남긴다.
2. 신규 길잡이는 원문 학습의 도입부이므로, 학습자가 필요로 하는 깊이의 독자 예제·실습을 더 작성할 수 있다. 페이지 수가 찼다고 원문 범위를 다 배웠다고 간주하지 않는다.
3. 사용자 실제 저장소에서 production build와 네이티브 브라우저 테스트를 실행하고 실패를 해결한다.
4. 공개 제공 범위의 권리를 확인한다. 원서 전체를 대체하는 번역판을 완료 목표로 설정한 경우에는 별도 승인된 콘텐츠 경로가 필요하다.

B.1 원문 링크는 공식 목차의 URL을 사용하되 이 환경의 웹 캐시에서는 본문 요청이 실패했다. 105개 링크 전부에 대한 라이브 HTTP 검사 완료로 취급하지 않는다.
