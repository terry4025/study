# 콘텐츠 작성 원칙과 현재 범위

대상은 미분·적분을 아직 배우지 않았고 프로그램의 함수·배열·인터페이스도 낯선 학습자입니다. 쉬운 비유는 유지하되, 근사·가정·실제 구현을 구분합니다.

## 새 수업의 구성

1. 일상 상황으로 ‘왜 필요한가’를 설명합니다.
2. 작은 숫자로 직접 계산합니다. 단위와 계산 과정을 생략하지 않습니다.
3. 수식은 기호를 문장으로 읽고 각 항의 의미를 설명합니다.
4. 렌더링에 어디에서 쓰이는지 연결합니다.
5. 성립 조건, 근사 모델의 한계와 흔한 오해를 설명합니다.
6. 학습자가 답을 선택한 뒤 설명을 보는 확인 문제를 제공합니다.

학습용 코드는 실제 PBRT 소스가 아니라 ‘독립 학습용 예제’로 표시합니다. 원문과의 문단별 대응을 주장하지 않습니다. 추정 학습 시간은 개인차가 큰 안내 값입니다.

9~16장의 24수업은 해당 **주제**를 다루는 입문 강의입니다. 9.1~16.5 각각의 번역이나 모든 내용을 포함한 대체 교재가 아닙니다. 기초 선수 링크는 준비 코스로 연결됩니다. 기초 코스 뒤의 기본 순서는 기존 1~8장 노트, 독자 9~16장 주제 수업입니다.

## 보존한 자료에 한 작업

- 2.1: 수렴 조건과 차원·비용 차이에 관한 정정 안내, 잘못된 요약 일부 대체.
- 4.1: 일부 방사휘도/휘도 표현과 ‘공리·절대 법칙’ 표현 정리, 모델 가정·센서 응답 주의.
- 5.2: 연속 래스터 샘플과 얇은 렌즈 근사에 관한 안내.
- 6.5: 원문 주 구현과 묄러–트룸보어를 혼동한 기존 화면 대신 짧은 독자 정정 해설 제공.
- 7.3: 노드 수 상한과 캐시 지역성 표현 일부 정리, 과도한 단정 안내.
- 8.1: 무작위/청색 잡음 구분과 캡션 연결 문제 안내, 요약 일부 대체.
- 전역: 누락된 equation 타입 표시, 원문 미검수 영어·코드·그림 캡션 구분.

원본 `src/data`를 바꾸는 것이 아니라 표시 어댑터에서 처리합니다. 따라서 다른 프로그램이 원본 콘텐츠 파일을 직접 가져가면 정정 전 내용이 남아 있습니다. 전체 번역·모든 문장을 교정한 상태로 표시하면 안 됩니다.

## 다음 검수 작업

그림 파일·그림 번호·의미·캡션을 함께 대조하고, 실제 영어 원문과 요약 영어를 구분하며, 1~8장 모든 문장의 조건·코드·수식을 확인해야 합니다. 이 작업은 아직 미완료입니다. 텍스트 유사도나 TypeScript 통과를 개념 정확성의 증거로 사용하지 않습니다.

## 안정적인 연결

기존 절 ID와 원본 파일은 유지합니다. 새 독자 수업은 `math-*`, `guide-*` ID로 구분합니다. 블록 ID를 발행 후 임의로 바꾸지 마세요. 메모·검색·읽기 위치가 블록 ID를 사용합니다. 내용 변경 시 기존 ID를 유지하고 교정 이력을 기록하세요.
